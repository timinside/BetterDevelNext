## ✨ Что такое FlaxyIDE?

FlaxyIDE берёт проверенную платформу DevelNext и превращает её в более плавную и современную среду для создания программ. Перетаскивайте компоненты на холст, пишите логику рядом и собирайте всё в самостоятельный `.exe`, который можно отправить кому угодно.

Никаких тяжёлых настроек. Никакого лабиринта из меню. Пишете вы свою первую программу или пятидесятую, FlaxyIDE сокращает путь от идеи до готового приложения.

## 🚀 Возможности

| | |
|---|---|
| 🎨 **Визуальный конструктор** | Создавайте интерфейсы, расставляя готовые компоненты, вместо ручного написания кода разметки. |
| 🛠️ **Полный набор для кодинга** | Пишите, редактируйте и обрабатывайте код в одном месте с богатым набором инструментов разработчика. |
| 📚 **Большая стандартная библиотека** | Используйте множество встроенных функций и классов, чтобы писать меньше шаблонного кода. |
| 📁 **Менеджер проектов** | Добавляйте, удаляйте, переименовывайте и упорядочивайте файлы и папки, не выходя из IDE. |
| 📦 **Сборка в один клик** | Компилируйте проект в самостоятельный исполняемый файл, готовый к распространению. |
| 🧭 **Современный интерфейс** | Обновлённый и интуитивный интерфейс для долгой и комфортной работы. |

## 🔄 Как это работает

**🆕 Создать** ➜ **🎨 Дизайн** ➜ **⌨️ Код** ➜ **▶️ Тест** ➜ **📦 Сборка** ➜ **🌍 Публикация**

1. **Создайте** новый проект в менеджере проектов.
2. **Оформите** окна в визуальном конструкторе.
3. **Напишите** поведение программы, используя стандартную библиотеку.
4. **Соберите** самостоятельный исполняемый файл и поделитесь им с миром.

### Установка за 4 шага

1. Скачайте установщик по ссылке выше.
2. Запустите `BetterDevelNextSetup.exe`.
3. Следуйте инструкциям на экране. Установщик предложит установить **bbruntime**, который нужен FlaxyIDE для корректной работы (пропускается автоматически, если он у вас уже есть).
4. Дождитесь окончания установки и запустите программу.

## ❓ Частые вопросы

<details>
<summary><b>FlaxyIDE подходит для новичков?</b></summary>

Да. Визуальный конструктор и встроенная библиотека позволяют быстро получить работающее приложение, а те же инструменты подходят и для более крупных проектов.
</details>

<details>
<summary><b>Что такое bbruntime и зачем установщик его просит?</b></summary>

Это компонент среды выполнения, который нужен FlaxyIDE для правильной работы. Если его нет, установщик предложит поставить его автоматически.
</details>

<details>
<summary><b>Можно ли делиться программами, которые я создаю?</b></summary>

Да. Проекты компилируются в самостоятельный исполняемый файл, поэтому их можно распространять, не заставляя людей устанавливать исходный код или саму IDE.
</details>

<details>
<summary><b>Я нашёл баг. Куда о нём сообщить?</b></summary>

Создайте issue во вкладке [Issues](https://github.com/timinside/BetterDevelNext/issues) с коротким описанием и шагами воспроизведения.
</details>
